# NovaLoop Driving Car

A simple driving car game made using HTML, CSS, and JavaScript.

## Features
- Moving car
- Score counter
- Keyboard controls
- Endless road

## Controls
- Left Arrow: Move Left
- Right Arrow: Move Right
